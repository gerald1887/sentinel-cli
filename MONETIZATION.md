# Monetization

Sentinel core (Phases 1–6 as released) is MIT-licensed. Core
functionality is intended to remain freely available.

Future commercial offerings, if any, will be developed separately from
this repository. Commercial work will focus on advanced compliance and
enterprise capabilities — such as hash-chained audit records, signed
attestations, tamper-evident chain of custody, and compliance report
generation — that go beyond the current open-source scope.

This document reflects current project intent and may evolve over time.
